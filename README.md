# Claude Accounts

Менеджер нескольких аккаунтов **Claude Code** для Windows. Переключает подписки одной кнопкой и показывает лимиты каждого аккаунта в реальном времени. Если на одном аккаунте закончились лимиты, нажимаешь «Запустить» на другом.

## Возможности

- **Быстрое нативное приложение** на [Tauri](https://tauri.app): установщик 2 МБ, окно открывается мгновенно, плавная смена темы и языка.
- **Неограниченное число аккаунтов.** Логин каждого хранится в своей папке через `CLAUDE_CONFIG_DIR`, так что делать logout/login не нужно.
- **Лимиты всегда перед глазами.** 5-часовой и недельный лимит показаны полосами с процентом и временем до сброса. Цвет полосы и точка на аватаре показывают статус: доступен, почти лимит, лимит исчерпан. Подробности — в подсказках при наведении, лишнего текста на карточке нет.
- **Бережно к серверу.** Лимиты запрашиваются не чаще раза в 5 минут, аккаунты по очереди. Если Claude Code сам недавно обновил лимиты, запрос не отправляется вовсе.
- **«Запустить лучший»** открывает аккаунт с наибольшим запасом лимитов.
- **Свой прокси у каждого аккаунта.** Прокси проверяется до добавления (задержка, IP, страна), и аккаунт с нерабочим прокси сохранить нельзя. Можно работать и без прокси.
- **Настройки запуска для каждого аккаунта:** режим полного доступа (`--dangerously-skip-permissions`), запуск терминала от имени администратора (через обычный запрос UAC), дополнительные аргументы (например, `--model opus`), цвет карточки.
- Выбор папки проекта: недавние папки, «Обзор», перетаскивание папки на окно.
- Окно перетаскивается за любое пустое место. Повторный запуск не открывает вторую копию, а поднимает уже открытое окно.
- Запуск в командной строке или в Windows Terminal.
- Уведомление, когда у аккаунта сбросился лимит.
- Синхронизация `settings.json`, skills и плагинов между аккаунтами.

## Требования

- Windows 10/11 с WebView2 (в Windows 11 он уже есть, на Windows 10 установщик докачает его сам)
- Установленный [Claude Code](https://docs.claude.com/en/docs/claude-code) (команда `claude` доступна в терминале)
- Подписка Claude (Pro или Max) на каждом аккаунте

## Установка

Скачай `Claude.Accounts_x.y.z_x64-setup.exe` со страницы [последнего релиза](https://github.com/hamura-ken/claude-accounts/releases/latest) и запусти. Установщик ставит приложение только для текущего пользователя (права администратора не нужны) и создаёт ярлыки на рабочем столе и в «Пуске». Удаляется через «Параметры → Приложения».

> Если Windows покажет предупреждение SmartScreen, нажми «Подробнее → Выполнить в любом случае». Установщик не подписан, весь код открыт в папке `app/`.

### Сборка из исходников

Нужны [Node.js](https://nodejs.org) 20+ и [Rust](https://rustup.rs).

```
cd app
npm install
npm run tauri build
```

Готовый exe появится в `app/src-tauri/target/release/`, установщик — в `app/src-tauri/target/release/bundle/nsis/`. Для разработки с горячей перезагрузкой: `npm run tauri dev`.

### Старая версия на PowerShell

Версия 4 (`Claude-Accounts.ps1`) по-прежнему работает и ничего не требует установки: запусти `Start.bat` или создай ярлык через `Create-Shortcut.bat`. Обе версии используют один и тот же конфиг, так что между ними можно переключаться.

## Как пользоваться

1. Открой приложение. Твой текущий логин Claude Code автоматически станет **Account 1**.
2. Нажми **«+ Добавить аккаунт»**: задай название, цвет и при необходимости прокси.
   - Если нужен прокси, выбери «Через прокси», вставь адрес и нажми **«Проверить»**. Поддерживаются форматы:
     - `host:port:логин:пароль`
     - `логин:пароль@host:port`
     - `http://логин:пароль@host:port`
     - `host:port` (прокси без пароля)
   - Подходят только HTTP-прокси. SOCKS Claude Code не поддерживает.
3. На карточке нового аккаунта нажми **«Войти в аккаунт»**. Откроется Claude, залогинься во второй аккаунт.
4. Готово. Выбери папку проекта и нажимай **«Запустить»** на нужном аккаунте или **«Запустить лучший»**.

Меню **«⋯»** на карточке: настройки аккаунта, обновить лимиты, открыть папку с логином, изменить порядок, выйти из аккаунта, убрать из списка.

Кнопка **⚙** в заголовке открывает общие настройки: частоту обновления лимитов, выбор терминала, сворачивание окна после запуска и синхронизацию настроек.

## Как это работает

- Каждый аккаунт хранится в своей папке: первый в стандартной `%USERPROFILE%\.claude`, остальные в `%USERPROFILE%\.claude-accN`. При запуске приложение задаёт `CLAUDE_CONFIG_DIR`, а также `HTTPS_PROXY`/`HTTP_PROXY`, если у аккаунта есть прокси.
- Лимиты обновляются раз в 5, 10, 15 или 30 минут (по умолчанию 5). Запрос идёт к тому же адресу Anthropic, который использует `/usage` в Claude Code, с токеном этого аккаунта и через его прокси. Аккаунты опрашиваются по очереди с паузой.
- Claude Code сам сохраняет последние лимиты в свой кэш. Если там свежие данные, приложение берёт их оттуда и в сеть не идёт. Если запрос не удался, тоже показываются данные из кэша.
- Если Anthropic ответил «слишком часто» (429), приложение выжидает: столько, сколько попросил сервер, иначе 5, 10, 20, затем 30 минут. Ручное обновление (кнопка или F5) не отправит запрос, если данным меньше минуты.
- Запущенный Claude получает чистое окружение: переменные вроде `NO_COLOR` или служебные `CLAUDE_CODE_*` (если само приложение открыто из другой сессии Claude Code) убираются, поэтому цвета и сохранение истории работают как обычно.
- Список аккаунтов и настройки приложения хранятся в `%USERPROFILE%\.claude-switcher.json`.
- Устройство кода: интерфейс на Svelte 5 + TypeScript (`app/src`), логика на Rust (`app/src-tauri/src`): конфиг, чтение логинов и кэша, сетевые запросы, запуск терминала.
- Приложение никуда не отправляет данные, кроме запросов к `api.anthropic.com`. При проверке прокси дополнительно запрашивается `ipinfo.io`, чтобы показать IP и страну.

## Частые вопросы

**На карточке написано «токен истёк».** Claude Code обновляет токен сам, пока аккаунт запущен. Если аккаунт давно не открывали, запусти его один раз, и живые лимиты снова заработают. Пока токен не обновлён, на карточке видны данные из кэша.

**В подсказке написано «Anthropic ограничил частоту запросов».** Сервер временно не отвечает на запросы лимитов с этого токена: обычно потому, что их же часто запрашивает сам Claude Code. Приложение подождёт и повторит само, а пока покажет последние известные данные.

**Как удалить аккаунт полностью?** Выбери «⋯ → Убрать из списка», затем удали папку `%USERPROFILE%\.claude-accN`. Открыть её можно через «⋯ → Открыть папку с логином».

**Как залогинить на карточке другой аккаунт?** Выбери «⋯ → Выйти из аккаунта», затем нажми «Войти в аккаунт».
